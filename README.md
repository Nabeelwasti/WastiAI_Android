# ⚡ Wasti AI — Next-Gen AI Assistant for Android

[![Android APK Build](https://github.com/Nabeelwasti/WastiAI_Android/actions/workflows/build-apk.yml/badge.svg)](https://github.com/Nabeelwasti/WastiAI_Android/actions/workflows/build-apk.yml)
[![Kotlin](https://img.shields.io/badge/Kotlin-1.9+-7F52FF.svg?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-M3-4285F4.svg?style=flat&logo=android&logoColor=white)](https://developer.android.com/jetpack/compose)

**Wasti AI** is an ultra-fast, multi-engine personal AI assistant built for Android using Kotlin and Jetpack Compose. It features instant multi-model AI reasoning, natural voice call simulation with customizable multi-gender personas, automated device controls, and seamless cloud integration.

---

## ✨ Features

- ⚡ **Groq Ultra-Fast AI Engine**: Powered by Llama 3.3 70B Versatile delivering blazing-fast 500+ tokens/sec response speeds.
- 🎙️ **Multi-Engine Voice & Audio**:
  - ElevenLabs Ultra-HD Neural Voice Engine integration.
  - Groq Speech AI Voice.
  - Custom Wasti Multi-Gender Voice Personas (Male, Female, Girl, Boy).
- 🧠 **Google Gemini AI Integration**: Native support for Gemini 1.5 / 2.0 models via Google AI Studio.
- 📱 **Automated Device Control**: Smart intent execution for flashlight, volume, Wi-Fi, battery, and system actions directly from voice or chat.
- 🎨 **Modern Material 3 UI**: Clean, dark/light dynamic theme built completely with Jetpack Compose.
- 🚀 **GitHub Actions CI/CD**: Automatic APK build and artifact generation on every commit.

---

## 📲 How to Download & Install APK

1. Go to the **[Actions](https://github.com/Nabeelwasti/WastiAI_Android/actions)** tab in this repository.
2. Select the latest successful build workflow run.
3. Scroll down to **Artifacts** and download `WastiAI-Debug-APK.zip`.
4. Extract the ZIP on your Android phone and install `app-debug.apk`.

## 🛠️ Built With

* **Language**: Kotlin
* **UI Framework**: Jetpack Compose (Material Design 3)
* **Architecture**: MVVM with Coroutines & StateFlow
* **Networking**: Ktor / OkHttp
* **CI/CD**: GitHub Actions
